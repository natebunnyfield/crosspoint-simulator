## 2. The s before an ascender: not one bearing [measured]

**Asked:** is the "s+ascender pushed open" pattern (sl, sk, sm, sh; Si) one s
right-side bearing that the model underfits?

**No.** In both styles, the mean residual (his value − model) over every pair
with **s on the left** is about 0. The same holds for a, e and o, which were
checked as controls.

| | s-left pairs | mean residual, in-sample | mean residual, held out (leave-one-pair-out) |
|---|---|---|---|
| roman | 19 | +0.1 | −0.2 |
| italic | 19 | +0.2 | +0.4 |

The s's right bearing is right on average. **The residual is pair-shaped,
and it goes both ways:**

| | his value | model |
|---|---|---|
| roman `sl` | +31 | +12.9 |
| roman `sh` | +12 | +8.2 |
| roman `sk` | +11 | +8.0 |
| roman `si` | −8 | +7.1 |
| roman `st` | −3 | +19.5 |
| italic `sl` | +26 | +8.5 |
| italic `sk` | +21 | +8.1 |
| italic `sh` | +18 | +6.4 |
| italic `sm` | +28 | +16.8 |
| italic `si` | −7 | +1.4 |
| italic `st` | −6 | +2.3 |

So s before a **tall stem with a left wedge serif** (h k l) wants **open**,
and s before **i or t** wants **tight**. A single bearing cannot do both.

**What the model lacks is a feature for the right glyph's ascender** (tall
ink at its left edge) interacting with the s's open right side. The current
38 features measure bands and profiles, but not that combination.

- **Candidate:** a feature for right-glyph left-edge ascender height × left
  glyph's upper-right openness. It would be tested by the same-fold CV before
  it is kept. **Proposed, not built.**
- **Capital `Si` (+36) is a separate family** (capital + i).
