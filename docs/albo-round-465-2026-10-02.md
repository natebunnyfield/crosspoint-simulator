## A commit that missed its code

The options commit (8c425ac, "the Bold S's width as options") went out
without its `outlines/build.py` hunk and the regenerated STATE. Another
agent committed in the same tree at the same moment (72b6271), and the index
lost those two paths between `git add` and `git commit`. The doc it carried
described a dial the tree did not have. This round's commit carries the dial,
at its shipped value.

**Lesson:** verify `git show --stat` before pushing whenever another agent is
active in the tree. Better, stage and commit in one command with explicit
paths: `git commit <paths>`.
