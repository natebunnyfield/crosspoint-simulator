# Albo round 461: the italic x (2026-10-02)

Owner, in order:

1. *"give me options for italic x"* (2026-10-01): arms X1, X2, X3.
2. *"X1 but with more options on bottom left"*: X1A to X1F.
3. *"make C and F options with thicker bottom left serifs"*: C1 to C3, F1 to F3.
4. **Ruling:** *"halfway between c1 & c2"*.

**Ships:** X1 with the C bottom left at 1.125 weight. These are the defaults
in `outlines/glyphs/aldine.py`: `ALBO_ALD_X_ARM` "X1C" and `ALBO_ALD_X_BL_W`
1.125. Setting `ALBO_ALD_X_ARM=""` (set, but empty) draws the round-457
letter. The measurements, the arms, the negative results and every option's
numbers are in `docs/albo-italic-x-2026-10-01.md`. This file records the ship.

## What changed

- **The italic x is drawn on ONE PEN** (`nib()`, the module's 50-degree
  edge). The rest of the italic is unchanged. The thick diagonal is 0.80 of
  the o's thick stroke in the Italic, where the references' median is 0.78
  and build 282 had 0.93.
- **The entry's crest is rounded into one arch, and the foot ends as it
  rises** instead of curling back over itself into a boot.
- **The bottom left is the C upturn.** The hairline reaches the baseline and
  cups up to the left, mirroring the thick stroke's foot. It is 1.125 of C1's
  weight, with the cup lifted and opened by the same rule as C2 and C3.
- **The Greek χ follows**, because it takes its proportions from the x
  (`greek_italic.py` `VIA_ROMAN`).
- **The whites around the x are kept** (`X_DLSB` +20, `X_DRSB` +6 Italic /
  +12 Bold Italic, applied to the x's own bearings in `aldine.py`, with λ and χ
  compensated in `build.fit_greek`). Without it every pair with x on the right
  lost exactly 20 units of the model's own band white. This was the
  adversarial review's first finding, reproduced below. With it every x pair
  measures +0 against build 282.

## Gates (on the combined round 461 + 462 build)

- **Outlines.** Only x and χ move in the Italic and Bold Italic (the a family
  moves in the Regular and Bold: round 462).
- **Every x pair's band white is +0 against build 282**, in both italics
  (`local_ai/b2_fit.xband_gap`): ex ix ax nx ux dx sx tx lx rx ox cx Ex hx Rx,
  and xe xa xi xo xu xp xy xt xc.
- **λ's metrics are unchanged** (548 / -3, 630 / -3). χ's are those of its own
  redrawn shape, and the same with or without the x's correction (592 / -35,
  662 / -36). The review measured them inside the references' spread
  (`greek376_space.py --fit` proposes the same sides).
- **POOR GATES: no delta** against build 282, all four cuts.
- **GATES UNCHANGED.** Approved letters unchanged; kern classes ok (Italic
  123 / 158, Bold Italic 123 / 160).
- **Clearance loop converged.** The R x kerns an earlier pass added (+8 / +17)
  were removed: with the whites kept, R x is back at build 282's distance and
  needs none. The only spacing-table change in this ship is round 462's Bold
  V ä.

## Adversarial review (read-only agent, 2026-10-02)

Five findings, ranked; what was done with each:

1. **Every pair with x on the right was 20 units tighter, and nothing
   refit it** (silent-wrong-output). Reproduced exactly (-20 on all 14 right
   pairs; -6 / -12 on the left). **Fixed** as above. This was round 409's
   re-basing applied to the one letter whose outline moved; a full refit
   would also re-space every italic redrawn since 409.
2. **A small sharp notch where the Bold Italic's entry arch turns into the
   thick** (cosmetic). Point #9 at (174, 380), a -122.5 degree reversal under
   the hair gate's 150 and the bump tool's 70-square-unit floor. It is a nick
   at drawing size and invisible at reading sizes; the old Bold Italic had a
   98.5-degree corner there. **Recorded, not fixed.**
3. **The pen-signature claim** (cosmetic, doc). The ratio did not move
   (0.64 → 0.60). **Corrected** in `docs/albo-italic-x-2026-10-01.md` §1.
4. **Latent dial issues:**
   - **An unknown `ALBO_ALD_X_ARM` silently drew the old x.** It now raises.
   - **A stale comment.** Fixed.
   - **The smoothing jump at exactly `X_BL_W` 1.0.** It does not touch the
     shipped 1.125, and is recorded.
   - **The 1.125 default also redraws X1F.** Reproducing round 459's C1 or F1
     now needs `ALBO_ALD_X_BL_W=1.0`.
5. **Provenance.** The x / n ink and the terminal widths had no committed
   script. Both are now `x_italic.py --ink`, which reproduces the docs'
   numbers (C1 42.9 / 62.4, C2 49.4 / 70.0). `d_dial` dials (X_BL_W, X_PEN_*,
   X_DLSB) are invisible to `gen_state.py`, as about 50 others are: a known
   limit.

**Checked and found clean** (the review's list): module state fixed at
import (every multi-weight tool runs one process per weight);
`x_nib`'s width pipeline (no steps, 2000-point sample); the C bottom left at
1.125 (formulas match the comments, the bottom stays on -15 / -28, one valid
polygon, 1.125 is the midpoint by built ink); `ALBO_ALD_X_ARM` "" draws the
old letter; kerns and gates (only R x changed then, touch 0 / 0, hairs 0); χ
and everything derived from x; the doc's section 1 and section 5 numbers,
reproduced.
