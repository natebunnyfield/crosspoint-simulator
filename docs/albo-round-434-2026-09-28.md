# Albo round 434 -- the Bold Italic c's top DRAWN, arm D3 (2026-09-28)

**The rulings that led here:**
- *"not enough rebalancing for bold italic so bottom is less and top is more. trace references if needed"* → T3 (bottom 0.49 of the stem).
- *"t3 but needs top read as a c better (the top sucks)"* → the hanging-swell arms X1/X3.
- *"much worse and worse, do better"* → the drawn arms D1–D3.
- *"d3 wins"*.

The full record of every arm, measurement and negative result is in `docs/albo-round-433-2026-09-28.md`, sections "Follow-up" and after. The method lesson is in `docs/albo-method.md`, "When a letter does not read as itself".

**A trap this found:**
- The drawn top reaches the t in the Italic's private c-t glyph (U+E004), taking it from 2 islands to 1.
- The Italic has a cut pass, so that re-cut the 28 glyphs after it (the Greek capitals, the f-ligatures).
- `PHASE_LEGACY_STYLE[('Italic', U+E004)] = 2` holds it (`outlines/build.py`); with it, only the c family and U+E004 move.
- `instruments/poor_gates.sh` had printed "no delta" over the count change; it now fails on one.
- Shipping any of these arms needs `cmp_contours.py --accept` with the reason.

All three pass touch, hairs and glitch.
